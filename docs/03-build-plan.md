# Phased Build Plan

## Phase 1: immediate usable launch
Ship the minimum that lets students log in and know what they own.

### Build first
- auth + roles
- home dashboard
- department dashboards
- C-suite dashboard
- seeded deliverables
- definitions of done
- approval rubric
- task tracker
- Gantt view (read-only)
- Sherpa Lite
- decision log

## Phase 2: core Bible production
- BMC builder
- Company Structure & Continuity module
- Bible view and chapter status
- goal/KPI tracker
- pricing and break-even engine

## Phase 3: pop-up and retail layer
- donation tracker
- transaction ledger
- customer feedback feed
- Phoenix Nest retail carry worksheet
- baked goods handling fields
- live mode page

## Suggested implementation order
1. auth
2. role-based dashboards
3. seeded deliverables and task tracker
4. approval workflow + rubric
5. decision log
6. Sherpa Lite
7. BMC
8. continuity
9. pricing engine
10. goals/KPIs
11. donation + retail worksheet
12. live mode

## Scope discipline
If time gets tight, cut polish before cutting seeded workflows.
