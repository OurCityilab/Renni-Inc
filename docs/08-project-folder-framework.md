## Suggested naming convention
- `YYYY-MM-DD_topic_version-owner.ext`
- Example: `2026-04-24_finance-pricing-v1-chase.xlsx`

## File ownership rule
Every file should have:
- one owner
- one reviewing chief
- one linked deliverable record in the portal
