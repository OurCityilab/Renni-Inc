# UX Requirements

## Product feel

Our City Studio should feel like a guided studio, a coach beside the student, a game board during simulations, and a portfolio builder.

It should not feel like a dense command center, spreadsheet, Canvas, corporate LMS, or project management tool.

## Mobile-first rules

One task per screen. Big buttons. Plain language. Autosave every input. Progress bar on every mission. Voice input where possible. Buttons: Make this better, Ask me questions, Explain this. No dense tables on mobile. No hidden navigation. No required drag-and-drop. Avoid multi-column layouts on phones.

## Desktop rules

Desktop may include side-by-side raw input and polished output, worksheet panel + AI panel, coach comments, export preview, simulation dashboard, P&L table, and leaderboard.

## Student screen patterns

Mission screen: title, why this matters, estimated time, start/continue button.

Worksheet screen: one prompt at a time, save indicator, skip for now option, example button.

AI improvement screen: Your words, Professional version, Why it works, What is missing, Try again.

Portfolio screen: artifact cards, draft/needs review/approved status, edit, export, ask AI to improve.

## Accessibility

Use readable font sizes, high contrast, keyboard navigation, screen-reader labels, captions/transcripts for video, and avoid color-only signals.
