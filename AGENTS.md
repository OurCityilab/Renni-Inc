# AGENTS.md

## Agent roles inside this repo

### Claude Code
Use for broad scaffolding, planning, full-stack feature building, and iterative codebase work.

### Codex
Use for focused implementation tasks, cleanup, refactors, bug fixes, and test passes.

## Shared rules
- Respect the product requirements in `docs/01-product-requirements.md`.
- Keep V1 lean.
- Seed the app before calling it ready.
- Approval rubric must be visible.
- Mobile responsiveness is required.
